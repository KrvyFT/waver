# Waver — Session Workstation

参考 Ableton Live 的紧凑浏览器、平面工作区及底部 Device View 分区，保留 Waver 的节点合成工作流。参考：https://www.ableton.com/en/live/learn-live/interface/

ui-ux-pro-max 检索采用 Minimalism & Swiss Style 中适用于桌面工具的网格、无阴影、清晰对比原则；不采用营销页结构。

## 布局

- 38 px 顶栏：品牌、Patch、工作区及音频连接状态。
- 左侧浏览器：192 px，窄窗口为 180 px；26 px 高的紧凑模块条目，开发中模块折叠。
- 中央信号画布：细网格、模块/连线计数，保留直接旋钮与连接操作。
- 底部 160 px 设备面板：模块信息、横向参数区、波形选择、编辑操作。
- 底部 26 px 状态栏：设备、采样率、声道、错误及未保存状态。
- 支持 1440×960 与 1000×640。全局无装饰动画。

## 色彩

暖灰底色、浅灰设备、深色正文、橙色选中标题和调参标记。输入为深蓝灰，输出/连线为棕色，并保留 IN/OUT 文字。不依赖颜色单独区分信号方向。

主题定义以 `crates/waver-ui/src/theme.rs` 为准。节点采用 2 px 圆角、无阴影和细边框；模块标题及数值保持明确层级。

## 验证和预览

`cargo test -p waver-ui` 检查布局、模块增删、波形联动和噪声参数。

`cargo run -p waver-ui --example preview` 打开静音原生预览；F6 在 1440×960 与 1000×640 之间切换。此快捷键仅用于预览。

此轮不新增音序器、混音台或录音功能，也不宣称自绘节点已具备完整屏幕阅读器支持。

紧凑节点：VCO 188×210，普通模块 156×112；旋钮直径 48，命中直径 52。保留 12–13 px 正文，优先收缩留白。
